# Changelog

All notable changes to the L&T Hazira Smart Manufacturing Analytics Platform will be documented here.

## [1.0.0] - 2026-11-22
### Added
- Complete star schema SQLite warehouse with 25,200 production records.
- Pre-shift failure risk prediction model and inference service.
- Interactive Streamlit operations dashboard with KPI metrics and charts.
- FastAPI REST microservice with OpenAPI schema.
- Comprehensive unit and integration test suite.
- Docker and Docker Compose containerization.
